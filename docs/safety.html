Safety and limits

This is the most important page on this site. Read it before you rely on Betar in an emergency.

Betar is not a replacement for emergency services where they exist. If a phone line, ambulance service or emergency broadcast is available to you, use it. Betar is for when none of those reach you.

Delivery is best effort

A message moves only when your phone comes within Bluetooth or Wi-Fi Direct range of another phone running Betar. There is no guarantee a message arrives, and no guarantee of how long it takes: minutes, hours, or never, depending entirely on which phones happen to be nearby and moving.

Betar cannot help if no other phone is in range. It carries messages between the phones that are actually present. It cannot conjure a path that does not exist.

No independent security review yet

The cryptography and protocol design follow established, published approaches, but the implementation has not yet had an independent audit. Treat it as you would any early-stage software handling sensitive communication: useful, actively developed, not yet independently verified.

What an emergency alert actually does

Sending an alert hands it to nearby phones, the same way any message travels. The app shows real counts (how many phones are carrying it, how many people acknowledged it), never an invented delivered status. Location sharing is off by default; turning it on helps people find you, and also means your location travels with the alert to everyone who receives it.

Report a security issue

If you find a security problem, please report it responsibly through the project's public repository rather than disclosing it publicly first.
